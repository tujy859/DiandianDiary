# 模型表单、聊聊导航与家庭页优化

2026-10-16。用户先整体确认四项方案，再修改当前 `main` 工作目录；保留已有照片保存修复及并行文档成果。运行页面以源码为准。

## 改动

- 模型配置：首次接入与后续设置共用 `templates/model-form.wxml`、`styles/model-source.wxss`，包括标题、来源、服务商、字段、帮助说明与恢复默认入口。事件交给各页面原有方法，测试不保存；引导保留步骤与确认继续，设置保留保存与清除。统一按钮名“测试连接”。
- 聊聊：宠物位于左侧，新话题 / 历史话题位于右侧；输入上方仅保留记录 / 查询快捷入口。长名字截断、空历史有提示，生成中或流程测试中沿用原有操作限制。
- 底部导航：修复高度内联值缺少 `height:` 的错误，原先 iOS 的高度与安全区声明可能整体失效。保留 112rpx 内容度量，底部安全区独立加入；图标改为 48rpx、文字 12px、每栏点击高度至少 44px，不改变切页与键盘恢复逻辑。
- 家庭页：当前家庭 / 成员简表 / 邀请优先；超过三位成员可展开查看全部。家庭切换、加入 / 创建、账号与家庭管理按需展开；无家庭自动展示创建 / 加入，断开云连接仍可展开账号设置退出本机。加入 / 创建 / 切换成功后收起旧区域，既有确认与权限流程保留。
