## 已确认的设计方向

整体采用“清爽耐看，带一点可爱”。保留暖白底、深绿主色，以杏橙少量点缀。减少厚重阴影和重复装饰，让照片、日记正文和宠物成为主角。

品牌小猫与宠物身份分开：抱日记本的小猫用于欢迎区、品牌区和空状态；宠物档案与宠物切换处使用真实宠物照片或可选默认头像。功能图标统一为圆润线性风格，常规操作继续复用已有图标库，逐步替换系统 emoji。

### 聊聊

- 保留适度大小的品牌小猫和简短邀请文案。
- 快捷入口使用短标题，如记件小事、上次洗澡、驱虫记录、最近状态。
- 减轻入口的视觉重量，保持输入区容易发现。

### 时光册

- 明确保留原有竖线与圆点时间轴，不能简化成只有卡片的列表。
- 日期与节点对齐，竖线使用浅绿、节点使用深绿。
- 照片得到更合理的展示面积，减小原来小方图右侧的大块空白。
- 正文突出，标签与相对日期弱化；保留时间轴与画廊切换。

### 我的与头像

- 用原始品牌 icon 替换占位猫头，压缩顶部品牌区高度。
- 宠物档案突出头像、名字和资料；删除操作可收进编辑页。
- 奶油橘猫已获认可，完整保留。
- 新增灰毛英长：参考用户真实猫照片的灰色长毛、金色眼睛、蓬松脸颊。
- 新增奶油小狗：杏色垂耳，与猫头像使用相同深棕轮廓和柔和配色。
- 后续接入添加/编辑宠物时的头像选择，并按宠物保存所选资源 ID；本阶段仅归档三个候选资源。
