## 使用

1. 保持现有 `utils/cloud-config.ts` 环境，并完成微信云端登录。
2. 在开始使用的「接入模型」，或「我的 → 模型连接配置」选择「微信云开发 AI」。
3. 设置页可以先「测试当前配置」再保存；测试不会自动保存。首次引导为「保存并测试连接」，失败后保留配置供重试。
4. 云开发模式不填写 Base URL / API Key。选择自定义 API 时仍使用原有 OpenAI 兼容接口；切换来源清空表单中另一来源的模型和凭证，保存前不改变已有配置。

云开发默认 `createModel('hunyuan-v3')` + `model: 'hy3'`，显式设置 `thinking: { type: 'disabled' }`。通道与模型分别定义在 `utils/cloud-ai.ts`，不能混用。

依据 [官方成长计划使用指南](https://docs.cloudbase.net/ai/ai-inspire-plan-guide)，该通道适用资源点及非资源点套餐，仅消耗符合条件的免费额度；额度耗尽会报错，不自动切换到 `cloudbase` 扣套餐额度。是否符合活动资格、剩余额度及模型可用性仍以账号控制台和实际调用为准。本轮不修改套餐、模型开关或计费配置。

[官方小程序接入说明](https://docs.cloudbase.net/ai/model/miniprogram-access)要求基础库至少 3.15.1；项目调试最低版本提高到 3.15.1，本机私有配置可选择更高版本。运行时同时检查版本与 `wx.cloud.extend.AI.createModel`，保存前也检查能力。旧版微信可以继续使用自定义 API。

## 数据与行为边界

- `ModelConfig.source` 可为 `cloud` / `custom`；旧配置缺少该字段时按自定义 API 使用，读取不重写旧配置。
- 两种模型继续共用当前工具、日期、引用与草稿校验。模型只生成待确认草稿，日记保存仍由用户确认触发。
- `generateText` 返回的 `choices[0].message.tool_calls` 与后续 `role: 'tool'` 消息保留原样，不启用 SDK 自动执行工具。
- 模型选择只保存在本机；云开发调用会向模型发送聊天文字与必要历史记录，不能将「配置不共享」解释为「聊天不上云」。照片处理沿用现有逻辑，没有新增图像识别能力。
- SDK 非流式接口没有 abort 句柄。本地取消 / 超时不会撤销已发出的云端生成，也不保证停止额度消耗；迟到结果不恢复 UI 或继续工具轮次。
- 本功能直接使用小程序云开发 AI SDK，不新增云函数，无需为此更新 `diaryApi`。现有登录与家庭业务仍需其后端。
