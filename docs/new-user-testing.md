# 测试家庭

本工具供开发者反复检查首次使用界面、空状态及首条记录，复用现有云端登录与家庭权限，不需要变更云函数。真实账号首次创建仍需另一微信账号或隔离环境验证。

「账号与家庭空间」页底部的退出登录会清除本机状态、回到欢迎页；再次连接仍是当前微信身份，云端已有宠物 / 日记和家庭保留。它不能替代独立空白家庭测试。退出会清除该账号的本机测试标记与返回目标，测试家庭本身保留，之后仍可在家庭列表管理。

## 入口

1. 在「我的」点击 5 次「关于记一下喵」（每次关闭关于弹窗）。
2. 开发者模式开启后，下方出现「开发者工具」分组。
3. 进入「测试家庭」。现有「开发自检」也放在该分组。

开发自检的「核心自检」只用隔离的内存演示数据，与默认自动化测试共用用例，不操作当前家庭缓存。「流程测试」则由用户显式启动，复用独立测试家庭并执行真实记录 / 查询动作；清理仅删除本轮已知日记和专用宠物，保留家庭供下次复用。内容、维护方式和覆盖边界见 [开发自检](developer-self-check.md)。

开发者模式在本机保留，切页或重新启动后仍可进入；普通界面默认隐藏入口。这个开关只控制客户端入口，不是云端权限。页面及引导演练参数也检查开关，所有云端操作仍由现有微信身份和家庭权限约束。

在「我的 → 开发者工具 → 关闭开发者模式」确认后隐藏工具，开关持久关闭并重置关于点击计数；以后重新点击 5 次关于可开启。取消不改变状态。关闭保留登录、模型配置与测试家庭数据，不自动退出 / 解散或切换家庭。仍处于测试家庭时提示条保留，点「管理 / 返回」进入普通家庭管理页，可切回原家庭。关闭期间，之前测试请求的迟到回包不能继续自动切换家庭；已经提交到云端的创建请求仍可能完成。

## 重走开始使用

通过开发工具进入引导演练，强制从「连接云端」开始，即使已有登录和模型配置也展示第二步。模型表单的密钥为空，便于检查必填提示、连接失败等场景。

- 不清除现有登录、家庭缓存或模型配置。
- 演练填写的模型配置只用于本次连接测试，不保存、不覆盖原配置；测试连接会实际请求所填模型服务。
- 可点「使用现有配置继续」，避免重复填写密钥或发起模型测试；进入应用后仍使用原有配置。
- 页面显示演练提示，可返回测试工具。普通引导的保存与校验行为保持原有逻辑。

## 进入空白测试家庭

连接正常后，工具先保存返回目标，再使用现有 `family.create`、`selectFamily` 接口创建 / 进入独立云端家庭。成功后重新打开聊天页，可从无宠物状态测试添加第一只宠物，再测试照片、待确认草稿、日记保存和时光册。

- 新建名称为「测试家庭 月/日 时:分:秒」，方便在家庭列表区分。已有家庭与待确认创建请求沿用原名称，不自动修改云端家庭。
- 最近的测试家庭仍无宠物且没有其他成员时复用，包括返回原家庭后再次进入；已有宠物或加入其他成员时另建。
- 原家庭的宠物、日记、照片和会话保留。测试期间保存的数据真实写入所选测试家庭，不属于原家庭。
- 聊聊、时光册、我的、家庭、引导及日记页显示测试家庭提示条，可点「管理 / 返回」进入工具页。
- 测试页显示当前家庭和可返回的原家庭；多次新建测试家庭时保留最初返回目标。在其他正常家庭重新发起测试时，以该家庭为返回目标。
- 创建请求标识、最近测试家庭和返回目标在本机按账号保存，不包含模型密钥。创建响应丢失可幂等重试，切换 / 返回失败保留恢复信息。

每个账号最多加入 10 个家庭，达到上限会显示现有业务限制，不自动清理家庭或数据。它适合覆盖首次使用流程，不等于创建新的微信账号。

测试结束后，可在「账号与家庭空间」选中测试家庭，由创建者点击「管理当前家庭 → 解散家庭」释放名额。解散关闭访问，云端数据暂时保留，不是永久清理。确认成功后同步清除该家庭的本机测试标记；原家庭已解散 / 退出时，刷新家庭列表会移除失效返回目标，不自动换成其他家庭。家庭管理的权限、计数与保留边界见 [家庭退出与解散](cloud-backend.md#家庭退出与解散2026-10-15)。

## 返回原家庭

点击测试页的「返回原家庭」。成功读取原家庭后重新打开「我的」，恢复原家庭的数据视图。测试家庭和测试数据保留，仍可在「账号与家庭空间」查看。

网络失败时留在测试家庭，保留返回按钮供重试。云端确认原家庭失去访问权限时明确提示、移除失效返回目标，并提供家庭管理入口，不静默切换到其他家庭。

- 家庭切换后重新创建页面，避免沿用上一家庭的页面会话；刷新节流与并发去重按账号 / 家庭区分，旧家庭请求不作为新家庭刷新结果。
