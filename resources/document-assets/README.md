# 项目说明书与演示素材

用于说明书、PPT 和 PDF 的参考资料、脱敏截图、图表数据及可编辑图稿。正式文稿与演示文件放在 [docs/deliverables/](../../docs/deliverables/README.md)。

有实际素材时按需建立 `references/`、`screenshots/`、`diagrams/`。素材清单记录文件、来源或授权情况、日期、版本、用途及截图是否为演示数据。外部资料可记录链接，不必复制完整文件。

品牌图、头像和插画复用相邻资源目录；历史 UX 预览通过链接引用，避免重复存放大文件。截图须脱敏，不包含密钥、账号标识、真实日记或私人照片。此目录不进入小程序包。
